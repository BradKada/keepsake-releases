# Keepsake releases

Installers for Keepsake by Mr. Robot, and the files installed copies read to find updates.

- Windows: `Keepsake-Setup-<version>.exe`. Installed copies download a new version on their own and install it when restarted.
- Mac: `Keepsake-<version>-arm64.dmg` (Apple silicon) or `-x64.dmg` (Intel). Installed copies download the new DMG, check it against `keepsake-mac.json`, and open it when asked; drag Keepsake into Applications to replace the old one.

The source is private. Each release's notes say what changed.
